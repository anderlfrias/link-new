# chat-interno

Monorepo gestionado con npm Workspaces.

## Estructura

- `backend/` — servidor Express + TypeScript
- `frontend/` — aplicación Next.js (App Router) + TypeScript

## Uso

```bash
npm install
npm run dev
```

`npm run dev` levanta backend y frontend simultáneamente. También están disponibles `dev:backend`, `dev:frontend` y `build`.
